FROM READING TO RUNNING

把项目串成实验路线.

按赛事阶段组织工作，让每一步都可验证。

01 / PROPOSAL

先把评测协议看清

从 OmniEEG-Bench 的模型接口和 task card 入手，用 EEG-Arena、EEG-FM-Bench 补充对照方案。确认被试划分、指标和训练预算。

查看评测项目 ↗
产出：任务矩阵 + 可复现评测设计
02 / BASELINE

先建立可信的起点

MNE / MNE-BIDS 统一通道、单位和采样率；Braindecode / EEGNet 建立轻量基线。SSVEP 增加 CCA / TRCA，防止复杂模型掩盖问题。

查看数据工具 ↗
产出：数据检查 + 分赛道强基线
03 / PRETRAIN

选一条可落地的预训练路线

优先检查 CBraMod、EEGPT、ST-EEGFormer 的训练链路；LaBraM 的离散 tokenizer 需重新训练。REVE、LUNA 等用于比较通道适配设计。

查看预训练项目 ↗
产出：从零训练 + 算力实测 + 消融
04 / VALIDATE

把收益落实到七赛道

在同一被试划分和预算下对比随机初始化、预训练、线性探针与全量微调。记录三种子均值与波动，并按官方规则计算最终分数。

查看任务方法 ↗
产出：分赛道结果 + 失败案例 + 复现包
优先消除三个常见偏差先按被试划分，再切窗，避免数据泄漏。分清 V 与 µV、参考电极和滤波条件。保持 SSVEP 频率与相位；预处理参数只在训练集确定。
